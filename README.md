# Industrial Predict AI

Plateforme intelligente de maintenance prédictive industrielle.

## Architecture

* Frontend : Angular + Nebular
* Backend : FastAPI
* Database : PostgreSQL
* Data Science : Pandas + Scikit-learn + XGBoost
* Infrastructure : Docker
* Versioning : Git + GitHub

## Structure

```text
industrial-predict/
├── backend/
├── frontend/
├── ml/
├── data/
├── notebooks/
├── tests/
└── docs/
```

## Objectif

Industrial Predict AI vise à détecter les risques de défaillance des équipements industriels afin d'aider les équipes de maintenance à planifier leurs interventions de manière proactive.
